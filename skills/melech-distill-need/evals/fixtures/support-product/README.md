# Queuewise fixture

Queuewise is a B2B support inbox used by 34 small SaaS companies. Agents work
from a shared queue. Incoming tickets are assigned manually or by five keyword
rules configured per workspace.

Current workflow:

1. Email and chat messages become tickets.
2. Keyword rules may assign a team and priority.
3. Unmatched tickets remain in the shared inbox.
4. A support lead reviews the queue and reassigns tickets.
5. Agents can correct team and priority before replying.

The product team is considering "automatic support-ticket triage," but has not
decided whether that means better rules, suggested labels, automatic routing, or
a separate analytics product. No implementation has been approved.
