# Artifacts for Problem Discovery

Produce artifacts only when requested or clearly useful.

## 1) Problem Validation Brief

Use when a decision is near.

Sections:
1. Decision to make
2. Segment and context
3. Problem statement (behavioral, not aspirational)
4. Evidence summary by signal tier
5. Alternatives and current spend/workarounds
6. Demand confidence and contradictions
7. Recommendation (Proceed/Refine/Hold/Stop)
8. Next validation move and threshold

## 2) Assumption & Evidence Ledger

Use when uncertainty is high.

Columns:
- Assumption
- Why it matters
- Current evidence
- Evidence strength (Tier 1–5)
- Risk if false
- Next test
- Owner
- Due date

## 3) Interview Guide (Discovery / JTBD)

Use for field research.

Include:
- target participant criteria
- 8–12 behavior-first questions
- anti-leading reminders
- coding rubric (frequency, severity, budget, trigger, barriers)

## 4) Segment Prioritization Matrix

Use when multiple ICPs are plausible.

Columns:
- Segment
- Pain frequency
- Pain severity
- Budget access
- Reachability
- Time-to-signal
- Weighted recommendation

## 5) Demand Signal Scorecard

Use for evidence-driven updates.

Rows:
- Signal
- Tier
- Source
- Date
- Interpretation
- Confidence
- Action implication

## 6) Decision Memo

Use for stakeholders/handoffs.

One page:
- What we believe now
- Why we believe it
- What could still be wrong
- What we will test next
- What decision changes at what threshold
