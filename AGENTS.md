# Repo Rules

## Maintenance Rule

Whenever adding, removing, or renaming anything under:

- `skills/`
- `commands/`
- `rules/`

you must also update `README.md`.

At minimum, keep the matching README section accurate:

- artifact name
- short description
- install instructions
- usage notes if behavior changed

Do not leave the repo in a state where the catalog in `README.md` is stale.
